A few useful answers

Frequently asked questions.

A little more about our team, our learning process and this website.

Who are the people behind M&F Web Studio?

We are Moses Oketch and Fred Karani, two Computer Science students working together on the CSC 216 Web Technologies Lab 2 project.

What technologies does this website use?

The website is built with plain HTML, CSS and JavaScript. It does not use a frontend framework or a template.

What can I explore on this website?

You can learn about the team, browse our project cards, filter and search projects, and try the contact form validation.

Does the contact form send an email?

Not yet. The form checks the information in your browser and displays a confirmation, but it is not connected to a server or email service.

How is the website published?

It is designed to be hosted for free with GitHub Pages from the root of the main branch of its GitHub repository.
